# Restaurant Analytics & Performance Dashboard

## Overview
An interactive Power BI dashboard analyzing restaurant listings to evaluate customer ratings, pricing tiers, and vote distributions across establishments.

## Key Metrics & Analysis (KPIs)
* **Total Restaurants Analyzed:** 4,503 listings evaluated.
* **Average Customer Rating:** 4.09 / 5.00 across all establishments.
* **Average Cost for Two:** 1.10K local currency units.
* **Highest Engagement:** Tamasha leads in total customer votes (5,016 votes).

## Tools & Technologies
* **Visualization:** Power BI Desktop
* **Data Processing:** Power Query (Data cleaning & modeling)
* **Reporting:** Visual report structuring & PDF exporting
